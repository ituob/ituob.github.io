Configure ITU OB Editor app

The guide describes how to configure the ITU OB Editor app after you launch it for the first time. These steps will only be needed for first-time launch.

  1. Create your own GitHub account, if you don’t have one yet, and log in.

    You can do so by navigating to GitHub.com/join.

  2. Launch the ITU OB Editor application. On the the welcome screen, click “Copy upstream repository URL” button.

  3. Open your favorite web browser, paste the upstream ITU OB data repository URL in its address bar, and go to that page.

  4. On the upstream repository’s page, click the button to create a fork.

    What’s a fork and what’s an upstream repository? Read about it here.

  5. When the fork is completed, and on your fork’s page, copy its URL from your web browser’s address bar and paste it in the welcome window of ITU OB Editor app.

    The URL should look like this: https://github.com/YOUR_USERNAME/itu-ob-data/

  6. Click “Launch with this repository URL” button.

  7. That’s it! The app will remember the repository URL and won’t show the initial configuration screen next time you launch it.

    If you want to reset repository URL later, you can do so using the Merge screen.
