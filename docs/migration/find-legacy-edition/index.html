Locate a Legacy OB Edition to Migrate

  1. Navigate to ITU.int Operational Bulletin Index and choose an edition to migrate to.

  2. On OB page, click download for the english version.

    Two options to download a PDF or a MS Word document.

    Microsoft Word format notes:

    • If an edition comes with an Annexed List, instead of a single MS Word document, download an archive containing OB Edition and Annexed Publication as two separate MS Word documents.
    • Recent OB Editions come in .docx format, but older ones may come in .doc.

  3. The downloaded file will contain the legacy data for the OB Edition.
