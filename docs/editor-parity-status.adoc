== Re-scoped

* *E5, one amendment per publication per issue.* The legacy amendment bundled every
  operation on a publication into one object, so "one per publication" was a
  structural rule. A patch is one action (`ADD`, `REP`, `SUP` ...), and an issue
  legitimately holds several per register, ordered by `seq`
  (`worker/lib/composer.ts` `listMergedUnpublished`). A uniqueness check would reject
  valid series, including the bulk import above. Status: DROPPED, superseded by per-action patches.
