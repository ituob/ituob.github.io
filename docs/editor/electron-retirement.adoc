= Retiring the Electron editor: parity and archive notice
:toc:
:toclevels: 2

Closes the last task of https://github.com/ituob/ituob.github.io/issues/101[#101]
("Retire Electron"). Source of truth for the row detail is
`docs/editor-feature-map.adoc` (IDs below are its IDs); this file is the
retirement decision: what each legacy feature became, what is left, and the text
of the notice for the Electron repository.

Legacy editor: `ituob/itu-ob-editor` at `74b1564`. Web editor: this branch
(`claude-a/101-electron-final`, on top of #130) plus `main` for the pieces that
merged there (#110, #117, #120, #121, #124).

== Where each piece lives

[cols="1,2",options="header"]
|===
| Location | Meaning
| main | merged: #110 screens, #117 parity, #120 catalog form (G1), #121 annexes (F1, F2), #124 telephone, custom title, SANC and mid (D6, D7, D14, D15, D18)
| #130 | open: byte preservation for 612 stored records, scheduling calendar (B6), inline help (B10)
|===

The earlier belief that telephone, custom title, mid and SANC authoring, SEED
and annexes were still missing is out of date: #124, #121 and #117 closed them.
What this branch adds is proof that an authored record has the shape the old
editor wrote (`src/lib/form/electron-authoring.test.ts`).

== What does not block retirement

* E4: the amendment header and `position_on` prefill. The date is entered by hand and checked by the validators. Track as a follow-up issue.
* I1 on general messages and the friendlier language picker (C7).

== What must happen outside this repository

These are not done here, deliberately.

. #130 and this branch merge into `main` (they conflict with current `main` in `docs/editor-feature-map.adoc`, `worker/lib/general-messages.ts` and `test/general-messages.node.ts`; the batch merge resolves them).
. Live proof: remote D1 migration, Cloudflare Access, the identity provider, the real repository import and the empty-register SEED check, one browser authoring pass per message type.
. A named owner adds the notice below to the Electron repository README and archives it. Nothing has been archived or edited.

== Archive notice (README of `ituob/itu-ob-editor`)

----
> **This application is retired.**
>
> The ITU Operational Bulletin is now edited in the web editor at
> https://github.com/ituob/ituob.github.io (pages under `/admin`, documented in
> `docs/editor/electron-retirement.adoc`). Sign in with your ITU account; changes
> go through review as pull requests instead of committing straight to the data
> repository.
>
> This repository is archived and read-only. It is kept for history only and is
> not maintained. Do not use it to edit `itu-ob-data`.
>
> Questions: open an issue on ituob/ituob.github.io.
----

Repository description to set when archiving: "Retired. Use the web editor in ituob/ituob.github.io."
