Sipme +883 (5130)

Communication of 14.I.2014

SIPME Limited , Kiryat Motzkin, recalls that the International Telecommunication Union (ITU) assigned the E.164 shared country code and identification code +883 5130 to Sipme Ltd on 16 September 2013 and it is being introduced on 1ST January 2014. Provisions must therefore be made in all countries with immediate effect, for callers to be able to dial the country code +883 5130 followed by the Subscriber Number (SN).

The initial +883 5130 dialling plan will consist of +883 5130 followed by eight (8) digits, (i.e +883 5130 XXXX XXXX).
