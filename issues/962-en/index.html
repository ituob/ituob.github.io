Dialling Plan

–            National

To dial a VoIP services number dial National Access Prefix (NAF) first then National Destination Code (NDC) and the Subscriber Number (SN):

NAF (0) + NDC + SN

–            International

To dial a VoIP services number dial International Access Prefix (IAP) (00) then Country Code (263) followed by the National Destination Code (NDC) and the Subscriber Number (SN):

IAP(00) +CC(263) + NDC + SN

Zimbabwe National Numbering Plan Country Code (CC) – +263

  • National Access Prefix (NAF) – ‘0’

The digit zero (‘0’) shall be used as a national access prefix, indicating a call to another geographic area, VoIP Services number or mobile services number.

  • International Access Prefix (IAP) – ‘00’

The digits ‘zero zero’ (‘00’) shall be used for international access indicating an international call or a call outside Zimbabwe.

  • Public Switched Telephone Networks (PSTN) – TelOne (Pvt) Ltd.

The public switched telephone network (PSTN) is divided into ninety-six geographic areas. Each of the geographic area is allocated an Area Code (AC).

  • Mobile Services

Mobile services are non-geographic and are allocated National Destination Codes as follows:

NetOne Cellular (Pvt) Ltd      71 Telecel Zimbabwe                    73 Econet Wireless                        91

 

  • Voice over Internet Protocol Services (VoIP) – ‘86XX’

VoIP services numbers are non-geographic and are allocated the codes ‘086XX’.

  • Dialling Plan

Local Dialling

A customer in the same geographic area shall only dial the Subscriber Number (SN) only National Dialling

A customer outside own geographic area shall dial National Access Prefix (NAF), Area Code (AC) plus the Subscriber Number (SN)

Dialled digits = NAF + AC + SN

A customer dialling Mobile Service or VoIP service number shall dial National Access Prefix (NAF), National Destination Code (NDC) plus the Subscriber Number (SN)

Dialled digits = NAF + NDC + SN

International Dialling

For international calls Dialled digits = IAP + CC + AC + SN 

Where a plus sign (+) is used, this indicates an international access prefix is required (e.g. +263 for Zimbabwe). This varies from country to country and it is ‘00’ for Zimbabwe 

A customer dialling Mobile Services or VoIP Services number shall dial: International Access Prefix (IAP), Country Code (CC), National Destination Code (NDC) plus the Subscriber Number (SN)

Dialled digits = IAP +CC + NDC + SN     (00263+NDC+SN)
