Malawi +265

Communication of 11.XII.2017

The Malawi Communications Regulatory Authority (MACRA), Blantyre, announces that Telekom Networks Malawi Plc has implemented a new number segment +26531.

The new segment will be used for its VOIP, non-SIM based services. The number segment will run in parallel with the existing +26588 range which is for all SIM based services.

General information:

The international public telecommunication number structure for this segment will have twelve (12) digits in all (including country code +265).

CC + N(S)N = twelve (12) digit number length, where:

CC is the country code consisting of three (3) digits and N(S)N is the National (Significant) Number consisting of nine (9) digits. In Malawi, the N(S)N is the same as the subscriber number (SN).
