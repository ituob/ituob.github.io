Communication of 30.IX.2011

The Ministry of Economic Affairs, Agriculture and Innovation , The Hague, announces that on 30 September 2011 Sint Maarten has taken the country code +1 721 into use in addition to the existing country code + 599.

This gives a temporal situation of permissive dialling, where either the current country code + 599 or the new country code +1 721 may be used for a dialled number terminating in Sint Maarten.
